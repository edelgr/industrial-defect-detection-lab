# Intellectual property and attribution review

Date: 2026-11-21 · Scope: the contents of the GitHub repository
`edelgr/industrial-defect-detection-lab` prepared for its first (private) push. This is a technical
review, **not legal advice**. The software code and the workshop presentation are reviewed
separately because they may have different owners, licences and third-party content.

## 0. Nature of the project
IDD Lab is a **personal, independent educational initiative** prepared for the CIARP 2026 workshop. It
is not presented as official software of any institution, and the repository contains no institutional
names, logos or trademarks (verified by search, §4). Whether any employer or institution has rights over
work produced in this context is a question for the owner to confirm (blocker **B2**).

### Proposed licence for the code — prepared, NOT applied
- Proposal: **Apache-2.0** (permissive, explicit patent grant, compatible with all dependencies used as
  installed libraries, same licence as Anomalib / timm / OpenCV).
- Prepared files: [LICENSE-Apache-2.0.proposed.txt](LICENSE-Apache-2.0.proposed.txt) (unmodified standard
  text, copied from an installed package's licence file and checked to run from
  "Apache License Version 2.0, January 2004" to "END OF TERMS AND CONDITIONS" plus the appendix) and
  [../../NOTICE.proposed](../../NOTICE.proposed).
- Not done on purpose: no root `LICENSE`, `pyproject.toml` still says *TO BE DECIDED*, no licence headers.
- Apply only after the owner confirms the right to license every affected component (B2) and decides B4.
- Scope: the licence would cover the code and the original documentation in this repository. It would
  **not** cover datasets, weights, third-party papers or the workshop presentation (§3).

## 2. Attribution in the repository
- Every dataset and method shown in the application links to its original paper, DOI, authors' code and
  licence page; BibTeX is provided (`CITATIONS.bib`).
- Results computed on third-party datasets are labelled *local educational* and never presented as
  official benchmark numbers.
- The synthetic data generator labels its output "Synthetic Educational Data — Not a Real Industrial
  Benchmark".

## 3. Workshop presentation (PowerPoint) — separate review, pending
**Status: file not yet provided; nothing about its content has been assumed or reconstructed.**
When the original file is provided it will be added unchanged to `workshop/CIARP2026/slides/` after this
checklist is completed by the owner:

- [ ] Authorship and ownership of the presentation confirmed (personal work vs. institutional template/material).
- [ ] Figures reproduced from papers: source cited on the slide; permission or licence allows reuse
      (open-access CC BY figures are reusable with attribution; publisher-copyright figures need permission or must be replaced).
- [ ] Dataset images: MVTec AD / LOCO / AD 2 images are CC BY-NC-SA 4.0 → attribution, non-commercial,
      **share-alike** (the slides containing them would have to be shared under compatible terms);
      MulSen-AD, VisA, Real3D-AD, Real-IAD D3, 3D-ADAM images: check each licence.
- [ ] Logos (conference, institutions, companies): remove or confirm permission; no institutional
      branding that suggests official endorsement.
- [ ] Slide template / theme: own, default Office theme, or licensed template that allows redistribution.
- [ ] Fonts: embedded fonts allow embedding/redistribution (or are not embedded).
- [ ] Photos, icons and clip art: source and licence recorded.
- [ ] Screenshots of IDD Lab: synthetic or catalog content only (as in `docs/screenshots/`).
- [ ] Speaker notes and hidden slides reviewed for personal or internal information.
- [ ] File metadata (author, company, comments, revision history) reviewed.
- [ ] Licence for the presentation decided separately (e.g. CC BY 4.0 for the author's own content, or
      "all rights reserved"); Apache-2.0 is a software licence and is not proposed for the slides.
