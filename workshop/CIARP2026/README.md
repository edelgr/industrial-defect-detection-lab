# CIARP 2026 Workshop — Industrial Defect Detection Lab

Materials for the workshop **"Industrial Defect Detection and Anomaly Analysis using Computer Vision,
Multimodal Imaging, and AI"** at CIARP 2026 (Mexico City), built around the IDD Lab desktop application.

These materials are part of a personal, independent educational initiative. They are not an official
publication of any institution or of the conference organisers.

| Folder | Contents |
|---|---|
| [guide/](guide/) | [Participant guide](guide/PARTICIPANT_GUIDE.md) (installation, schedule, exercises) and [Instructor guide](guide/INSTRUCTOR_GUIDE.md) (preparation, verified presets, activity timing) |
| [exercises/](exercises/README.md) | Index of the eight hands-on exercise sheets (the sheets themselves live in [docs/exercises/](../../docs/exercises/) because the application opens them from there) |
| [references/](references/README.md) | Scientific references used in the workshop, with a BibTeX subset of the project catalog |
| [slides/](slides/README.md) | Workshop presentation — **to be added from the original file**; not yet included |

## Before the workshop
1. Install the Student Edition: [STUDENT_QUICK_START.md](../../STUDENT_QUICK_START.md).
2. Run the readiness check: `python -m scripts.readiness --profile student`.
3. Read the [Participant guide](guide/PARTICIPANT_GUIDE.md).

No dataset or model checkpoint is distributed with these materials; see
[DATASETS.md](../../DATASETS.md) and [docs/REDISTRIBUTION_POLICY.md](../../docs/REDISTRIBUTION_POLICY.md).
