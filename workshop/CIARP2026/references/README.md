# Scientific references for the workshop

All references come from the project's verified research catalog (`research_catalog/`); the complete
list with DOIs, open PDFs, official code and dataset pages is in
[RESEARCH_REFERENCES.md](../../../RESEARCH_REFERENCES.md) and [CITATIONS.bib](../../../CITATIONS.bib).
[workshop_references.bib](workshop_references.bib) is a verbatim subset of `CITATIONS.bib`.

## Benchmarks discussed
- Bergmann et al., *MVTec AD — A Comprehensive Real-World Dataset for Unsupervised Anomaly Detection*, CVPR 2019; extended version in IJCV 2021.
- Bergmann et al., *Beyond Dents and Scratches: Logical Constraints in Unsupervised Anomaly Detection and Localization* (MVTec LOCO AD), IJCV 2022.
- Heckler-Kram et al., *The MVTec AD 2 Dataset: Advanced Scenarios for Unsupervised Anomaly Detection*, IJCV 2026.
- Liu et al., *Real3D-AD: A Dataset of Point Cloud Anomaly Detection*, NeurIPS 2023.
- Li et al., *Multi-Sensor Object Anomaly Detection: Unifying Appearance, Geometry, and Internal Properties* (MulSen-AD), CVPR 2025.
- Zhu et al., *Real-IAD D3: A Real-World 2D/Pseudo-3D/3D Dataset for Industrial Anomaly Detection*, CVPR 2025.
- McHard et al., *3D-ADAM: A Dataset for 3D Anomaly Detection in Additive Manufacturing*, ICRA 2026.

## Methods used in the exercises
- Defard et al., *PaDiM: A Patch Distribution Modeling Framework for Anomaly Detection and Localization*, ICPR Workshops 2021.
- Roth et al., *Towards Total Recall in Industrial Anomaly Detection* (PatchCore), CVPR 2022.
- Batzner, Heckler and König, *EfficientAD: Accurate Visual Anomaly Detection at Millisecond-Level Latencies*, WACV 2024.
- Damm et al., *AnomalyDINO: Boosting Patch-Based Few-Shot Anomaly Detection with DINOv2*, WACV 2025.
- Jeong et al., *WinCLIP: Zero-/Few-Shot Anomaly Classification and Segmentation*, CVPR 2023.
- Guo et al., *Dinomaly: The Less Is More Philosophy in Multi-Class Unsupervised Anomaly Detection*, CVPR 2025 (explanation only).
- Wang et al., *Multimodal Industrial Anomaly Detection via Hybrid Fusion* (M3DM), CVPR 2023 (explanation only).
- Oquab et al., *DINOv2: Learning Robust Visual Features without Supervision*, TMLR 2024 (feature backbone).
- Akcay et al., *Anomalib: A Deep Learning Library for Anomaly Detection*, ICIP 2022 (implementation used).
